# Deutsch A0–B1 — тренажер німецької граматики та письма

Інтерактивний застосунок для швидкого опанування німецької мови рівня **A0–B1**: активне пригадування (active recall) + інтервальне повторення (метод Лейтнера). 39 модулів (граматика + письмо), 390 SRS-завдань трьох типів, пояснення українською.

**Письмо (Schreiben)** — окремий фокус, побудований за принципом scaffolding:

1. **Фрази як формули** — 4 SRS-модулі рівня «✍️» (структура листа, Redemittel, сполучники, типові речення) — автоматично потрапляють у щоденну сесію повторення.
2. **Речення** — Lückentext (4 листи з пропусками ключових фраз) і переклад UA→DE (24 іспитові речення з толерантною перевіркою та самооцінкою).
3. **Повні листи** — 8 завдань у форматі іспиту B1 (Leitpunkte, лічильник слів, чек-лист, зразки відповідей).

Плюс **план на 14 днів** до іспиту (граматика + письмо щодня, чекбокси прогресу) та кнопки ä/ö/ü/ß для набору без німецької розкладки.

**Мови інтерфейсу (19):** українська, русский, English, Polski, Español, Français, Italiano, Română, Türkçe, Deutsch, Български, Hrvatski/Srpski, Magyar, Português, العربية (RTL), فارسی (RTL), Tiếng Việt, 中文, हिन्दी — вибір на стартовому екрані (з емблемою школи SprachHaus) та перемикач у шапці. Для арабської та фарсі інтерфейс дзеркалиться справа наліво. Перекладено інтерфейс, назви модулів/рівнів, розділ письма (ситуації завдань, чек-листи, підказки, речення для перекладу) та план. Пояснення до граматичних завдань наразі українською.

## Програма для Windows та Mac (desktop)

Готові інсталятори збираються автоматично через GitHub Actions і лежать у розділі **[Releases](https://github.com/OiGeNchecK/ik148-quiz/releases)**:

- **Windows:** `Deutsch-B1-Setup-<версія>.exe` — запусти, програма встановиться і з'явиться в меню «Пуск».
  ⚠️ Інсталятор не підписаний, тому SmartScreen покаже попередження: натисни **«Докладніше» → «Все одно виконати»**.
- **macOS:** `Deutsch-B1-<версія>-mac.dmg` (universal — Intel і Apple Silicon) — відкрий і перетягни програму в Applications.
  ⚠️ Застосунок не нотаризований: при першому запуску macOS заблокує його. Відкрий **Системні налаштування → Конфіденційність і безпека → «Відкрити попри все» (Open Anyway)**, або клацни по програмі правою кнопкою → «Відкрити».

Нову версію інсталяторів можна зібрати, запушивши тег `v*` (наприклад `v1.2.0`) або запустивши workflow **Desktop builds** вручну у вкладці Actions.

Локальна збірка: `npm run dist` (збирає інсталятор для поточної ОС у `dist-electron/`).

## Встановлення як програми (PWA)

Застосунок — це PWA: його можна встановити як звичайну програму, і він **працює офлайн**.

**Windows (Chrome або Edge):**
1. Відкрий https://oigencheck.github.io/ik148-quiz/
2. В адресному рядку праворуч з'явиться іконка встановлення (⊕ / монітор зі стрілкою) → натисни **«Інсталювати»**.
   Або меню ⋮ → «Зберегти і поділитися» → «Інсталювати сторінку як застосунок».
3. Програма з'явиться в меню «Пуск», відкривається у власному вікні.

**iPhone / iPad (Safari):**
1. Відкрий сайт у **Safari** (саме в Safari, не в Chrome).
2. Натисни кнопку «Поділитися» (квадрат зі стрілкою вгору).
3. Прокрути вниз → **«На екран Домівки» (Add to Home Screen)** → «Додати».
4. На домашньому екрані з'явиться іконка «Deutsch B1» — відкривається на весь екран, як звичайний застосунок.

**Android (Chrome):** меню ⋮ → «Додати на головний екран» / банер «Встановити застосунок».

Прогрес зберігається локально на пристрої. Щоб перенести його між пристроями, використовуй «⬇ Зберегти прогрес» / «⬆ Завантажити прогрес» на головному екрані.

## Деплой на GitHub Pages

Є **два способи**. Спосіб А (через Actions) — рекомендований: пушиш код, далі все автоматично.

### Спосіб А — автоматичний (GitHub Actions)

1. Створи новий репозиторій на GitHub (наприклад `german-b1`).
2. Залий код:
   ```bash
   git init
   git add .
   git commit -m "German B1 grammar trainer"
   git branch -M main
   git remote add origin https://github.com/ТВІЙ_НІК/german-b1.git
   git push -u origin main
   ```
3. На GitHub відкрий репозиторій → **Settings** → **Pages**.
4. У розділі **Build and deployment** → **Source** обери **GitHub Actions**.
5. Готово. Workflow `.github/workflows/deploy.yml` збере й опублікує застосунок автоматично. За хвилину-дві адреса з'явиться там же, у Settings → Pages (вигляд: `https://ТВІЙ_НІК.github.io/german-b1/`).

Кожен наступний `git push` у гілку `main` автоматично оновлює сайт.

### Спосіб Б — вручну (гілка gh-pages)

1. Залий код у репозиторій (кроки 1–2 вище).
2. Виконай:
   ```bash
   npm install
   npm run deploy
   ```
   Це збере проєкт і запушить вміст у гілку `gh-pages`.
3. **Settings** → **Pages** → **Source**: обери гілку **gh-pages**, папка **/ (root)** → **Save**.

## Чому працює під будь-яким ім'ям репозиторію

У `vite.config.js` встановлено `base: "./"` — шляхи до ресурсів відносні, тож застосунок коректно відкривається з підкаталогу `/<repo>/` без ручного редагування під назву репозиторію.

## Збереження прогресу

Прогрес (SRS-картки, серія днів, чернетки листів) автоматично зберігається в `localStorage` браузера — нічого не втрачається між сесіями чи перезавантаженнями сторінки. Кнопки **«Зберегти прогрес»** / **«Завантажити прогрес»** на головному екрані додатково експортують та імпортують JSON-файл — використовуй їх, щоб перенести прогрес на інший пристрій або зробити резервну копію.
